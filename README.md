# Disease Prediction from Medical Data using Machine Learning

## 📌 Project Overview

This project predicts the possibility of heart disease using patient-related medical data and machine learning classification algorithms.

The project compares multiple machine learning models and identifies the model with the best prediction accuracy.

## 🎯 Objective

To develop a machine learning model that can analyze structured medical data and predict the possibility of heart disease.

## 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* XGBoost

## 🤖 Machine Learning Algorithms

The following classification algorithms are used:

1. Logistic Regression
2. Support Vector Machine (SVM)
3. Random Forest
4. XGBoost

## 📊 Dataset

The dataset contains patient-related features such as:

* Age
* Sex
* Chest pain type
* Blood pressure
* Cholesterol
* Heart rate
* Exercise-induced angina
* Other medical features

The target column represents the prediction class.

> **Note:** The dataset used for this educational project is synthetic and is not intended for real-world medical diagnosis.

## 📈 Model Evaluation

The models are evaluated using:

* Accuracy Score
* Classification Report
* Confusion Matrix

The model with the highest accuracy is selected as the best-performing model for this project.
